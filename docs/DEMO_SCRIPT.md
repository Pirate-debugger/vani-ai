# Vani AI — 90-Second Founder Demo Script

## Overview
This script demonstrates Vani AI's voice-first, multilingual capabilities, real-time web intelligence, enterprise document generation, and reviewer critic engine in under 90 seconds.

---

## Scene 1: Voice-First Hinglish Interaction (00:00 - 00:25)

**Action**: User opens Vani AI workspace. Clicks microphone orb (or uses push-to-talk).

**Founder Voice (Hinglish)**:
> *"Vani, mujhe Pune ke students ke liye ek hostel and PG finding platform banana hai. Pehle competitors ka pricing aur amenities compare karo, aur fir ek complete Enterprise BRD draft karo."*

**Vani Response (Audio + Visual Stream)**:
- Live transcription appears in real-time with Indian language font support.
- Research pipeline activates: TinyFish live web fetch queries top competitors (Stanza Living, Zolostays, local PGs).
- Vani speaks back in Hindi/English (Sarvam Bulbul v3):
  > *"Sure! Pune market me Stanza Living aur Zolo top competitors hain jinka average rent ₹8,000 se ₹16,000 per bed hai. Mai aapka 29-section Enterprise BRD live generate kar rahi hoon."*

---

## Scene 2: Enterprise BRD Generation & Evidence Citations (00:25 - 00:50)

**Action**: Document streaming view displays real-time sections.
- Sections materialize: Executive Summary, Market Opportunity, 29 Enterprise FRs & NFRs, UPI/KYC Integrations, and Startup India/Udyam compliance notes.
- Right panel `EvidenceInspector` highlights live web sources and pricing citations with timestamps.
- Action items are automatically extracted into the project Task Board.

---

## Scene 3: Reviewer / Critic Pass & Competitor Watch (00:50 - 01:15)

**Action**: Founder clicks **"Run AI Critic Review"** or says:
> *"Vani, is BRD ko audit karo for gaps."*

**Visual Result**:
- The **Reviewer Critic Agent** scores the document (e.g., 94/100).
- Suggests actionable enhancements:
  - *"Add offline PIN fallback for biometric check-in during rural network drops."*
  - *"Include UPI AutoPay regulation timeline for deposit refunds."*
- Founder clicks **"Schedule Competitor Watch"**:
  - Sets up daily automated monitoring of competitor pricing pages with instant diff alerts.

---

## Scene 4: Export & Integration (01:15 - 01:30)

**Action**:
- Founder clicks **"Sync to GitHub"** — tasks are instantly created as GitHub Issues.
- Downloads the BRD as clean Markdown / PDF.
- Founder closes with:
  > *"From spoken idea to researched, audit-verified BRD in 90 seconds."*
